# The Torture Client!

While this may not have a lot of features currently, any release will work with a blank yaml as long as there are no APWorld changes!
Currently this client includes:

* Server \& Player Information
* Deathlink Sending
* Random / Targeted Trap Sending
* \* Private Messaging

For more information, please see the [Help Guide](https://github.com/ElectroStarz/Torture-AP-Client/blob/main/docs/admin_help.md) on the GitHub!

If you would like to request features, please feel free to do so!

* This feature is only compatible with the Torture User Client. If you are a developer, [read here](https://github.com/ElectroStarz/Torture-AP-Client/blob/main/docs/integrating.md) if you want to integrate the Torture User Client with your client.
